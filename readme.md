# words

Word counting as a circuits laboratory.

This repository is a worked example for [circuits](https://github.com/tonyday567/circuits): a file-processing pipeline built from `Trace` components, with explicit Handle wiring and per-stage metering via [circuits-meter](https://github.com/tonyday567/circuits-meter).

See `app/Main.hs` for the main pipeline and `examples/` for smaller recipes.
